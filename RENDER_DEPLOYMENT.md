# Render Deployment Guide

## Prerequisites

1. A Render account (https://render.com)
2. This repository pushed to GitHub
3. Set up environment variables in Render

## Deployment Steps

### 1. Connect Repository to Render

1. Go to [render.com](https://render.com) and sign in
2. Click "New +" and select "Web Service"
3. Connect your GitHub repository
4. Select this repository

### 2. Configure Environment Variables

In the Render dashboard, add the following environment variables:

- **SECRET_KEY**: Generate a secure key using `python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"`
- **DEBUG**: `False`
- **ALLOWED_HOSTS**: Your Render app domain (e.g., `lavender-todo.onrender.com`)

Render will automatically provide `DATABASE_URL` for PostgreSQL.

### 3. Deploy

1. Set the following in Render's build and start commands:
   - **Build Command**: `bash build.sh`
   - **Start Command**: `gunicorn todoproject.wsgi`

2. Click "Deploy"

### 4. Create Superuser (First Time Only)

After deployment, run in your terminal:

```bash
render exec lavender-todo -- python manage.py createsuperuser
```

Or use Render's shell in the dashboard.

## Environment Variables Reference

| Variable | Required | Example |
|----------|----------|---------|
| SECRET_KEY | Yes | Auto-generated by Django |
| DEBUG | No | False (default) |
| ALLOWED_HOSTS | No | lavender-todo.onrender.com,localhost |
| DATABASE_URL | No | Provided by Render PostgreSQL |

## Important Notes

- **Never commit `.env` file** to Git
- Static files are automatically collected during build via `build.sh`
- Database migrations run automatically on each deploy via Procfile
- Use a strong SECRET_KEY in production
- HTTPS is automatically enabled by Render

## Monitoring

- View logs in Render dashboard
- Use `render logs` for CLI access
- Database can be managed in Render PostgreSQL dashboard

## Troubleshooting

**502 Bad Gateway**
- Check logs for migration errors
- Verify SECRET_KEY is set
- Ensure ALLOWED_HOSTS includes your Render domain

**Static files not loading**
- Run: `render exec your-app-name -- python manage.py collectstatic`
- Verify STATICFILES_STORAGE setting

**Database errors**
- Verify DATABASE_URL is set in environment
- Check PostgreSQL instance is running in Render
